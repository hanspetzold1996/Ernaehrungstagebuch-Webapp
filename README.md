# Ernährungstagebuch (eigenständige Web-App)

Ernährungs- und Beschwerdetagebuch für das iPhone. Läuft ohne Anmeldung, ohne Server und ohne Internet (nach dem ersten Öffnen).
Alle Einträge bleiben auf dem Gerät.

## So kommt die App ins Internet (GitHub Pages, kostenlos)

1. In Safari auf **github.com** anmelden (oder ein kostenloses Konto anlegen).
2. Oben rechts auf **+** und **New repository** tippen. Name zum Beispiel `ernaehrungstagebuch`, Sichtbarkeit **Public**, dann **Create repository**.
   Im Repository liegt kein persönlicher Inhalt, die Einträge bleiben auf dem Gerät der Nutzerin oder des Nutzers.
3. Im neuen Repository auf **uploading an existing file** tippen (oder **Add file → Upload files**).
4. Die entpackten Dateien auswählen, alle **7** zusammen:
   `index.html`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `README.md`
   (Das ZIP vorher in der Dateien-App durch Antippen entpacken.) Dann unten **Commit changes**.
5. Oben auf **Settings**, links auf **Pages**. Unter **Branch** `main` und `/ (root)` wählen, **Save**.
6. Nach 1 bis 2 Minuten erscheint oben die Adresse: `https://DEIN-NAME.github.io/ernaehrungstagebuch/`

## Auf dem iPhone installieren

1. Die Adresse in **Safari** öffnen (nicht in einem anderen Browser).
2. **Teilen-Symbol** (Quadrat mit Pfeil) → **Zum Home-Bildschirm** → **Hinzufügen**.
3. Die App immer über das Symbol auf dem Home-Bildschirm starten.

## Wichtig

- Die Einträge liegen nur auf diesem iPhone. Unter **Mehr → Sicherung speichern** regelmäßig eine Sicherung anlegen. Löscht man die App oder die Safari-Daten, sind die Einträge sonst weg.
- Updates: Neue Dateien ins Repository hochladen (gleiche Namen ersetzen die alten). Die App holt sie beim nächsten Öffnen mit Internet.
- Eine Benachrichtigung auf dem Sperrbildschirm gibt es nicht. Die App zeigt beim Öffnen einen Hinweis, wenn heute noch nichts eingetragen ist. Für eine echte Erinnerung eine tägliche Erinnerung in der iPhone-App „Erinnerungen" anlegen.
